# FC TORO - Système de Gestion du Club (SMG)

Système de gestion globale et tableau de bord administratif pour le **Football Club TORO (FC TORO)**.

> **Conçu et développé par [OCTACORE](https://www.octacore.io/).**

---

## ⚽ Présentation

Cette plateforme sur-mesure permet d'administrer l'ensemble des activités du **FC TORO** :
- **Gestion des Joueurs** : fiches complètes, catégories (Ti Toro, U8 à U18), documents et suivi.
- **Gestion des Parents & Employés / Coachs** : attribution des droits et contrôles d'accès par rôle.
- **Finances & Paiements** : factures, reçu automatique en PDF, suivi bidevise (USD & HTG), paiements en retard.
- **Evénements & Agenda** : calendrier interactif et convocations.
- **Tableau de bord Analytique** : graphiques et métriques dynamiques.

---

## 🚀 Technologies

- **Framework** : Next.js 16 (App Router)
- **UI & Style** : React 19, Tailwind CSS V4
- **Langage** : TypeScript
- **Base de données & Auth** : Supabase
- **Génération de PDF & Emails** : pdf-lib, jspdf, Nodemailer

---

## ⚙️ Installation & Lancement local

1. Installez les dépendances :
   ```bash
   npm install
   ```

2. Lancez le serveur de développement :
   ```bash
   npm run dev
   ```

3. Créez un build de production :
   ```bash
   npm run build
   ```
